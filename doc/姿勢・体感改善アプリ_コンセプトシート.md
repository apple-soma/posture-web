# 姿勢・体感改善アプリ コンセプトシート

> 2026-11-14 時点のスナップショット（同日夜、MVPに向けた決定事項を反映）。以前の編集版は https://claude.ai/artifact/Bqb7ZtMVH2pLAmULHEo4p8 にあるが、本ファイルの方が新しい。機能・データ設計の詳細は同じフォルダの「姿勢・体感改善アプリ_仕様書.md」（仕様書 v2.8）。

## コンセプト

**人に寄り添い、生涯の生活を豊かにするためのアプリです。**

スマホで撮影した姿勢を数値で測り、基準値と比べて、今の状態とどこを改善すべきかを分かりやすく示します。本人が感じている悩み（凝りや痛みなど）も踏まえて優先すべき運動を提案し、再測定で変化を確かめます。この「測定→運動→再測定」を繰り返すことで、年齢や暮らしが変わっても姿勢を整え続けられる、伴走型のサービスを目指します。

大切にすること

- 姿勢を感覚ではなく数値で捉える。毎回できるだけ同じ条件で測れるようにする
- 測定結果だけでなく、本人の悩みも踏まえて改善方法を決める
- 1回測って終わりにせず、再測定で変化を確かめ続ける
- 写真はスマホの中で解析し、サーバーに送らない

しないこと

- 医療診断をしない。測定値だけで病気や原因を断定しない
- 強い痛みなどがある人には、アプリで対処させず医療機関への相談を促す

## ターゲットユーザー（仮説）

初期ターゲットは、35〜50歳のデスクワーカーという仮説です。肩や背中の張り、姿勢の崩れが気になっているものの、自分の姿勢がどうなっていて、どこを直せばよいか分からない人を想定しています。インタビューと実際の使われ方を見て見直します。

使う場面

- 正面と側面から姿勢を撮影して、今の状態を数値で知りたい
- 自分の姿勢と悩みに合った運動を教えてほしい
- しばらく運動を続けた後に測り直して、どれだけ変わったか確かめたい

## 課題（仮説）

姿勢が崩れている自覚はあっても、どこがどれだけ崩れていて、何をすればよいかが分からない。これが中心の課題という仮説です。

- **自分の姿勢を客観的に見られない：** 鏡や感覚では、頭の前への突き出しや肩の左右差を正確につかめない
- **何をすればよいか分からない：** 運動の情報は多いが、自分の姿勢と悩みに合うものを選べない
- **効果が分からない：** 運動を続けても変化が数字で見えず、やめてしまう
- **専門家に見てもらうのは負担が大きい：** 整体や理学療法には費用と時間がかかる

## 提供価値と主要機能

提供する価値は、姿勢を数値で知り、自分に合う運動で改善し、その変化を数字で実感できることです。次のサイクルを繰り返して使います。

1. 姿勢を撮影して測る
2. 基準値と比べて評価する
3. 気になる部位や悩みを聞く
4. おすすめの運動を提案する
5. 実施した運動を記録する
6. 一定期間後に測り直し、変化を確かめる（その結果で次の運動を提案し、1に戻る）

| 機能 | 内容 |
| --- | --- |
| 姿勢撮影 | 正面と側面から撮影する。毎回同じ条件で撮れるようにガイドを出す |
| 姿勢測定 | 体の目印（頭・肩・骨盤・膝・足首など）を自動で検出し、CVA（頭の前への突き出しの角度）、肩や骨盤の左右差、体幹の傾き、首の傾きなどを算出する |
| 姿勢評価 | 研究論文などの基準値と比べ、指標ごとに「目安の範囲」「頭がやや前に出ている」のように、目安と比べた状態を言葉で示す。総合姿勢スコアはMVPでは出さない |
| 測定結果の表示 | 測定値、基準値、前回との差（誤差の範囲内なら「変化なし」）、改善ポイントを見せる |
| ヒアリング | 気になる部位（首、肩、肩甲骨、背中、腰、骨盤など）、悩みの種類（凝り、痛み、重さ、動かしにくさ、見た目）、気になる度合い（0〜10）を記録する |
| 運動推薦 | 測定結果とヒアリングを組み合わせて、優先すべき運動とその方法・回数・時間を示す |
| 運動の記録 | 実施した運動、回数、続けた日数を記録して習慣化を支える |
| 再測定・改善の比較 | 初回と同じ項目を測り直し、角度などの変化をグラフで見せる |
| 履歴 | 過去の測定結果、運動の実施履歴を残す |
| 安全性・注意表示 | 医療診断ではないことを明示し、強い痛みがあれば医療機関への相談を促す |

## 差別化ポイント（仮説）

測って終わりではなく、測定・悩み・運動・再測定を1つのサイクルにつなげ、変化を数字で確かめられることが差別化の中心です。競合調査はまだなので、以下は仮説です。

- **数値で測る：** 研究や理学療法で使われる指標で測り、基準値と並べて見せる
- **悩みも踏まえる：** 測定値だけでなく、本人の悩みを組み合わせて運動を選ぶ
- **変化が数字で見える：** 初回と現在を比べ、何がどれだけ変わったかをグラフで確かめられる
- **写真を送らない：** 解析はスマホのブラウザ内で行い、サーバーには測定結果だけを保存する

## ビジネスモデル（仮説）

無料で測定と評価を体験してもらい、改善を続けたい人に月額約680円で課金してもらうフリーミアムを想定しています。価格も、無料と有料の境界もまだ決まっていません。

| プラン | 価格（仮説） | 提供内容の方向性 |
| --- | --- | --- |
| 無料 | 0円 | 姿勢の測定と評価、基本的な運動の提案 |
| 有料 | 月額約680円 | 再測定と改善の比較、履歴と推移グラフ、悩みに合わせた運動プログラム |

支払う意向は、アンケートの回答ではなく実際の申込みで確かめます。

## 制約・リスク

最大のリスクは、評価に使う基準値の根拠と、スマホ写真での測定精度です。測定と評価がアプリの柱なので、ここが崩れると価値そのものが成り立ちません。

| リスク | 内容 | 対策 |
| --- | --- | --- |
| 基準値の根拠 | 研究の基準値は、測り方・姿勢・対象者によって異なる。スマホ写真での測定にそのまま当てはまるとは限らない。研究上の判定基準があるのは現状CVAのみ | 採用する基準値ごとに出典と測定条件を記録し、アプリ内でも示す。肩・骨盤は「アプリ独自の仮の目安」と明記する |
| 測定精度 | 撮影の角度・距離・服装・立ち方で角度に誤差が出る。肩・骨盤の左右差は小さく、誤差と同じくらいになるおそれがある | 撮影ガイドで条件をそろえる。検出の信頼度が低いときは撮り直しを促す。使ってもらう前に繰り返し測ってばらつきを調べ、それより小さい変化は「変化なし」とする。ばらつきが大きければ肩・骨盤の判定をやめる |
| 医療・効果の表現 | 判定の言葉や「肩こりが治る」などの表現が、診断や効能の表示に見えると、薬機法や景品表示法などに触れるおそれがある | 「正常／異常」を使わず、目安と比べた状態を言葉で示す。医療診断ではないことを明示する。一般公開の前に専門家に確認する |
| 運動推薦の安全性 | 痛みがある人に合わない運動を勧めてしまうおそれがある。MVPでは専門家の監修を受けられない | 強い痛みやしびれがある場合は運動を出さず、受診を促す。痛みのある部位の運動は出さない。運動を負担の小さいものに絞る。一般公開の前に理学療法士などの監修を受ける |
| 続かない | 再測定まで運動が続かず、変化を実感する前にやめてしまう | 運動の記録と続けた日数を見せる。MVPでは週1回の再測定を運営から案内する |
| プライバシー | 体の写真や悩みは、健康に関わる個人情報 | 写真はサーバーに送らず保存もしない。保存するデータ・運営が見ること・削除の方法を説明し、同意を取る |

## 対応プラットフォームと技術構成

スマホのブラウザで使うWebアプリとして作ります。姿勢の解析はブラウザの中で行い、サーバーには写真ではなく測定結果（角度などの数値）とランドマーク座標だけを保存します。

| 役割 | 採用する技術 |
| --- | --- |
| Webアプリ本体 | Next.js |
| 公開（ホスティング） | Vercel |
| データの保存（ユーザー情報・記録・測定履歴）とログイン | Supabase |
| 姿勢の解析（ブラウザ内） | MediaPipe |

## 進め方

最初に、測定の精度と基準値の根拠を確かめます。ここが成り立つことを確認してから、段階ごとに検証して進めます。

1. **測定の検証：** MediaPipe で同じ人を繰り返し測り、ばらつきを調べる
2. **問題の理解：** ターゲットに近い人5〜8人にインタビューし、困りごとと測定への期待を確かめる
3. **MVPの実使用：** 測定・評価・運動推薦・再測定を使ってもらい、結果が伝わるか、運動と再測定まで続くかを見る
4. **課金の検証：** 無料案と月額約680円の案を示し、実際の申込みと解約理由を見る
5. **拡張：** 運動の個別化やAIの活用を、安全性・プライバシー・運用費を踏まえて検討する

## MVPに向けて決めたこと（2026-11-14）

詳細は仕様書v2.8の該当節を参照。

- [x] **MVPに入れる機能の範囲**：招待した検証参加者（5〜8人）向け。測定・項目別の評価・前回との差・ヒアリング・運動推薦・運動記録・再測定・簡易な比較・同意画面・Supabase保存を入れる。総合スコア・通知・推移グラフ・写真保存・課金は入れない（1.2節）
- [x] **採用する測定項目と基準値、その出典**：判定するのはCVA（50°／45.5°の2本の線で3段階）、肩・骨盤の左右差（3°の仮の目安）。体幹の左右の傾き・首の傾き・体幹の前傾は表示のみ（第6章）
- [x] **「変化あり」とみなす最小の差**：仮にCVA 5°、肩・骨盤 2°。使ってもらう前に繰り返し測定して正式な値にする（6.3節）
- [x] **判定に使う言葉**：「正常／異常」は使わず、指標ごとに目安と比べた状態を言葉で示す（9.1節）
- [x] **保存するデータ**：測定値・ランドマーク座標・ヒアリング・運動記録など。写真は保存しない。運営が見ることを同意画面に明記する（8.1節）
- [x] **アカウントの方式**：メールに届く6桁のコードでログイン、招待制（4.1節）
- [x] **再測定の間隔**：MVPは週1回、合計3回（5.8節）
- [x] **運動コンテンツの用意の仕方と監修**：MVPは監修なしで、負担の小さい運動に絞り、安全側のルールで始める。一般公開の前に監修を受ける（5.6.1節）

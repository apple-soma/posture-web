# Posture Check Web MVP

スマホのブラウザで姿勢を撮影・測定し、目安と比べた評価と運動の提案、再測定による変化の確認を行う Next.js + TypeScript の Web アプリです。写真は端末内で解析し、サーバーには送りません。

## ドキュメント

- [コンセプトシート](doc/姿勢・体感改善アプリ_コンセプトシート.md)：アプリの目的・対象・方針の要約
- [仕様書](doc/姿勢・体感改善アプリ_仕様書.md)：機能・測定指標・データ設計・MVPの範囲と作業順。実装状況は 1.1 節、作業順は第10章

## 起動

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開きます。カメラを使うため、本番環境では HTTPS（または localhost）が必要です。

## 注意

医療診断用ではありません。測定値は撮影条件（距離・カメラの高さ・体の向き）によって変わります。

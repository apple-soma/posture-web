# Posture Check Web MVP

姿勢撮影・測定・参考評価・運動候補の提示を行う Next.js + TypeScript Webサービスです。

## 実装済み
- 正面・側面それぞれ上半身／下半身の分割カメラ撮影（自動撮影・音声ガイド・音声「OK」撮影）
- MediaPipe Pose Landmarker による33ランドマーク検出（端末内で解析）
- 正面：肩ライン・骨盤ラインの左右傾斜（画素座標で算出。＋は画像右側が高い）
- 側面：股関節を通る垂直基準線に対する耳・肩・股関節・膝・足首の前後位置（正規化座標）
- 側面・上半身の写真でC7を1点タップし、耳ランドマークとの関係からCVAを算出
- CVAの研究カットオフ（45.5°）との比較による参考評価
- 目的・時間・場所に応じた運動候補の提示と実施ログ（localStorage）
- スマホ対応レスポンシブUI

## 未実装

## CVAについて
MediaPipe Pose LandmarkerにはC7ランドマークがありません。そのため「MediaPipeだけでCVAを自動計算」とはせず、側面写真でC7をユーザーが指定します。耳ランドマークはMediaPipeで自動取得します。

CVA 45.5°は、Mostafaee et al. (2024) が軽度FHPと中等度〜重度FHPを識別する最適カットオフとして報告した値を使用しています。
肩・骨盤の傾きと前後位置には現在登録された評価基準がなく、測定値のみを表示します。

## 起動
```bash
npm install
npm run dev
```
ブラウザで http://localhost:3000 を開きます。

カメラAPIは本番環境では HTTPS または localhost が必要です。

## 注意
- 医療診断用ではありません。
- 写真の距離・カメラ高さ・身体の向きによって測定値は変動します。
- 本格運用前に、測定再現性・妥当性の検証が必要です。

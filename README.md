# Posture Check Web MVP

姿勢撮影・測定・評価・結果表示の4機能に絞った Next.js + TypeScript Webサービスです。

## 実装済み
- 正面・側面のカメラ撮影
- 写真アップロードのフォールバック
- 撮影ガイド
- MediaPipe Pose Landmarker による33ランドマーク検出
- 肩の左右傾斜、骨盤の左右傾斜、体幹傾斜の自動算出
- 側面写真でC7を1点タップし、耳ランドマークとの関係からCVAを算出
- CVAおよび暫定閾値による3段階評価
- 総合姿勢スコア
- localStorageによる前回測定との差分表示
- スマホ対応レスポンシブUI

## CVAについて
MediaPipe Pose LandmarkerにはC7ランドマークがありません。そのため「MediaPipeだけでCVAを自動計算」とはせず、側面写真でC7をユーザーが指定します。耳ランドマークはMediaPipeで自動取得します。

CVA 45.5°は、Mostafaee et al. (2024) が軽度FHPと中等度〜重度FHPを識別する最適カットオフとして報告した値を使用しています。
肩・骨盤・体幹の 2° / 5° は普遍的な診断基準ではなく、本MVPの経過観察用暫定値です。

## 起動
```bash
npm install
npm run dev
```
ブラウザで http://localhost:3000 を開きます。

カメラAPIは本番環境では HTTPS または localhost が必要です。

## 注意
- 医療診断用ではありません。
- 写真の距離・カメラ高さ・身体の向きによって測定値は変動します。
- 本格運用前に、測定再現性・妥当性の検証が必要です。
